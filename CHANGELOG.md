# Changelog

## 1.0.0 - 2026-10-08

- Respect reduced motion for reveals, navigation, image effects and scripted scrolling. Show all clients in a wrapping static list when motion is reduced.
- Make the mobile menu inert when closed, manage keyboard focus, close with Escape and support short landscape screens.
- Add shared fluid typography, section spacing and bounded page gutters.
- Improve heading wrapping, long email handling, card metadata and layouts with enlarged text.
- Add consistent keyboard outlines, 44px icon/menu controls, press feedback and hover effects scoped to precise pointers.
- Add contact validation messages, growing message input, autofill hints and an explicit email-draft handoff.

Contact delivery still uses the visitor's email app. Existing newsletter, social and article placeholders are outside this six-item CSS/usability release.
